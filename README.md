# EVA-0 project page

Project website for **EVA-0: Test-Time Model Evolution with Only Two Forward Passes per Sample**.

- Website: https://cascol-chen.github.io/EVA-0-project-page/
- Paper: https://arxiv.org/abs/2605.18867

This repository hosts the project website. `index.html` contains the page, embedded figures, styles, and animations. Google Fonts supplies the web fonts. No build step is needed.

GitHub Pages publishes the root of the `main` branch. To update the website, replace `index.html` with the revised page, commit, and push to `main`.
